# Student Interface Project

This project implements a simple Student interface in TypeScript and renders a table of students using Vanilla JavaScript.

## Setup

1. Navigate to the project directory:
   ```bash
   cd 0x04-TypeScript/task_0
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Build the project:
   ```bash
   npm run build
   ```

## Files
- `js/main.ts`: Main TypeScript logic.
- `package.json`: Project dependencies and scripts.
- `tsconfig.json`: TypeScript configuration.
- `webpack.config.js`: Webpack configuration.
